# 204 英语：界面与操作重构

2026-09-11。重构前代码为 `202c955`，工作分支为 `refactor/ui-20260911`。范围覆盖登录、复习、真题阅读、句库、新增、学习记录及外观和声音设置。

## 使用场景

面向同时经常使用电脑和手机的个人考研英语学习者。主要过程是阅读真题、标记不熟悉的词、留下句子，再在周期复习中反复理解。界面围绕阅读内容与当前动作安排，编辑、音色和详细关联信息按需展开。

## 页面与操作

| 场景 | 新的操作方式 |
| --- | --- |
| 日常复习 | 默认逐句专注，也可切换列表浏览；听整句、看译文、完成本次是三项独立操作 |
| 查看安排 | 显示本轮完成次数、剩余次数、切换时间；重复句子显示“本轮第 1 / 2 次” |
| 理解长句 | 英文衬线阅读字体；译文预留位置，显示和隐藏时不推移重点词及操作栏，显示后可进一步查看双语分块 |
| 学习重点词 | 词与释义保留在句子下方，支持点词或喇叭听音，保留键盘快捷键 |
| 真题阅读 | 今日推荐与文章目录；手机先选文章再进入正文，可返回选择其他文章 |
| 阅读标注 | 选中单词后标记重点，明确显示待保存、保存中、已保存；支持手动立即保存 |
| 留下句子 | 勾选标注句后“加入句库”，按钮附近显示结果，并说明新句子在下一轮加入复习 |
| 查找与维护 | 句库顶部搜索与排序，列表以英文和译文为主，展开后编辑、换音色或删除 |
| 新增与导入 | 单句和批量导入分为两种方式；重点词使用带标签的词义和提示输入框 |
| 学习记录 | 分别统计完成安排、整句听音、重点词听音；保留旧系统累计记录 |
| 个性化设置 | 日间、夜间、跟随系统；标准和大字阅读；朗读音色与试听 |

电脑使用侧栏导航与较宽的阅读区，宽屏复习显示本页安排。手机使用底部导航，主要复习操作保持在底部导航上方。所有主要页面适配两种配色。

外观沿用 `study-theme` 存储键并兼容旧的 light/dark 选择。首次加载在渲染前应用主题；选择跟随系统时响应设备配色变化。字号和复习显示方式在当前设备保存。

## 保留的业务规则

- 排序和本轮重复次数继续采用用户设计的两套曝光计算。
- 同一句的每次安排独立完成；完成本轮不表示句子退出后续复习。
- 七天周期、北京时间 08:00 边界、提前完成后等待下一边界、中途新增句子进入下一轮，均沿用原后端规则。
- 独立导入句子继续有效，无需补文章关联。
- 保留翻译、词义、音频、历史累计与现有学习进度。本次没有迁移数据库或批量重新生成内容。

## 实现与可靠性

- `useEnglishActivity.js` 独立管理统计和热力数据，统计刷新不会再覆盖复习安排或搜索列表的总数。
- 列表请求带有顺序保护，旧页面响应不能覆盖当前页面；句库搜索不再带入复习轮次。
- `passagePresentation.js` 提取文章表单转换和展示规则；加入句库、完成阅读的异步结果保留等待期间的新编辑，也不会把页面切回此前的文章。
- Vue Router 导航守卫集中处理未保存内容，覆盖导航按钮、页面链接与浏览器前进后退；退出登录保护未保存句子草稿。
- 音频预加载在切换页面时取消；已失效的结果不再写入缓存。保留最多三个并发请求。
- 公共分页、重点词展示和阅读偏好各自独立，英语专属样式在 `frontend/src/english/styles/`。
